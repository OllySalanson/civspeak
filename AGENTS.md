# Project agent memory

This file is the project's committed home for project-intrinsic agent knowledge: build, test, release, architecture, and sharp-edge notes that should travel with the code.

- Setup, commands and how it works: `README.md`. Tests and lint: `.venv/bin/python -m pytest -q`, `.venv/bin/ruff check src tests tools`.
- Never commit Firaxis or mod text, game files, the built index or the key. `tools/repo_guard.py` enforces this (pre-commit hook via `git config core.hooksPath .githooks`, and `tests/test_repo_guard.py`). Test fixtures are invented and live only in `tests/conftest.py`.
- Game data comes from the captain's PC at run time: `DebugGameplay.sqlite` (rules of the last loaded game) plus the `Modding.log` text replay. Page stats are a port of the game's `CivilopediaPage_*.lua` (latest expansion's version wins) plus the Better Civilopedia mod's layouts (workshop item 1341630847); read those files before changing `src/civspeak/pedia.py`, and bump `SCHEMA_VERSION` in `index.py` when page output changes so existing indexes rebuild.
- The API key is read only from `~/.config/civspeak/anthropic-key` (`%LOCALAPPDATA%\Civspeak` under Windows' own Python); never print or log it. Real API calls count against the $10/month ledger `spend.jsonl` in the data folder (`paths.data_dir()`); tests use a fake client.
- Voice: Kokoro model files are shared from `~/.local/share/pixel-explainer`, Whisper `base.en` from `~/.cache/huggingface` (`paths.py`); never download at run time or commit models or audio. Tests use fake Kokoro/Whisper (`tests/test_voice.py`); `tools/voice_check.py` exercises the real spoken path against a running server and spends real money.
- Windows helper (`src/civspeak/winhelper.py`): runs under Windows' own Python, so standard library only and Python 3.10+; it must stay importable on Linux (ctypes/winreg only inside functions) because `tests/test_talk.py` tests its logic there. Exercise the Windows half by running a copy with `python.exe` from WSL (interop shares the captain's desktop); check `GetLastInputInfo` first and never take focus, open windows or inject keys while he is using the PC.
- Windows app (`src/civspeak/app.py`, `civspeak app`): one process; pywebview needs the main thread, `winhelper.Helper` (tray, `` ` ``, shared with the WSL route's `WslHelper`) and the server run on threads. The app records and plays George itself (`conversation.py`, `audio.py`, sounddevice); its page never touches audio and only mirrors `/api/talk` events, while the WSL route's page still records and plays. Test native audio without sound in the room: patch `audio.read_clip` to return silence and feed a Kokoro-voiced WAV as the microphone. App and WSL helper share one single-instance lock and Run value (`Civspeak`), so only one runs. Native test sharp edges: a `WM_CLOSE` posted from outside arrives as `TaskManagerClosing` and really closes (the X is `SC_CLOSE`); a scripted launch never gets the focus, so capture the window with `PrintWindow`; start Windows programs from WSL as a background task, as `cmd /c start ""` quoting breaks.
- Two runtimes: WSL (the captain's install today) and Windows' own Python (the coming Windows app). Game discovery for both goes through `paths.WindowsView` (registry, `libraryfolders.vdf`, Epic manifests, known Documents folder); OS differences (priority, child processes, registry, known folders) live in `system.py`. Windows refuses to replace or delete a file another process has open, so never `os.replace` over a live file: the index is versioned (`index-<n>.sqlite`, see `index.py`). Test natively with a copy of the source under `%TEMP%` run by `python.exe` from WSL at below normal priority, deleted after; HF cache files are Linux symlinks Windows cannot follow over `\\wsl.localhost`, so copy models with `cp -L`.
- Shared 10GB machine: build the index at low priority (`civspeak build` does this), never search `/mnt/c` recursively (`paths.py` uses fixed paths, registry values and shallow globs only; `Sid Meier's Civilization VI*` would also match Civ VII's folders).
